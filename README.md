# Sda-LCL-proyecto-alumnado
En esta Situación de Aprendizaje investigaréis cómo la educación puede transformar vidas y sociedades. Analizaréis textos, debatiréis ideas y trabajaréis cooperativamente para crear un mensaje propio. Durante cuatro semanas desarrollaréis una conferencia y materiales visuales que reflejen vuestra visión del poder educativo.
